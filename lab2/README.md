# Лабораторная работа №2 — Линейная алгебра

Лабораторная работа посвящена применению линейной алгебры для работы с векторами, матрицами и данными.

## Содержание

В ноутбуке рассмотрены:

1. Векторы и операции над ними.
2. Матрица данных и матричные операции.
3. Линейные отображения.
4. Определитель и ранг матриц.
5. Базис и координаты в новом базисе.
6. Системы линейных уравнений.
7. Проекция вектора на прямую.
8. Метод наименьших квадратов и линейная регрессия.
9. Метод главных компонент (PCA).
10. Сингулярное разложение (SVD).
11. Итоговая связь рассмотренных понятий.

Все вычисления выполнены в Python с использованием NumPy. Для построения графиков используется Matplotlib.

## Установка

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать его в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установить зависимости:

```bash
pip install -e .
```

## Запуск


После запуска открыть файл:

