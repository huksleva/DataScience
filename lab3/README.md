## О проекте

Проект содержит две лабораторные работы по машинному обучению, посвящённые деревьям решений и ансамблевым методам.

В работах рассматриваются:

* алгоритм CART;
* критерии качества разбиения;
* классификационные деревья;
* подбор гиперпараметров;
* ансамблевые методы;
* оценка качества моделей;
* анализ важности признаков;
* предотвращение утечки данных;
* методология CRISP-DM.

## Лабораторная работа №1

### Реализация CART с нуля

В первой лабораторной работе реализуется классификационное дерево решений CART без использования готовой реализации дерева из `scikit-learn`.

Используется датасет **Rice Cammeo and Osmancik**.

В работе выполнены:

* загрузка данных из ARFF;
* исследование структуры датасета;
* предварительный анализ данных;
* перемешивание данных;
* проверка инвариантов;
* кодирование целевой переменной;
* стратифицированное разделение данных на обучающую, валидационную и тестовую выборки;
* расчёт критерия Джини;
* расчёт энтропии;
* поиск оптимальных порогов разбиения;
* реализация класса узла дерева;
* реализация классификатора CART;
* тестирование алгоритма на небольших наборах данных;
* визуализация дерева;
* расчёт важности признаков;
* построение матрицы ошибок;
* подбор гиперпараметров;
* сравнение собственной реализации с `DecisionTreeClassifier`;
* оценка итоговой модели на тестовой выборке.

Для воспроизводимости экспериментов используется `random_state=42`.

## Лабораторная работа №2

### Деревья и ансамбли в sklearn по CRISP-DM

Во второй лабораторной работе исследуются алгоритмы классификации из `scikit-learn` на датасете **Bank Marketing**.

Работа построена в соответствии с методологией **CRISP-DM**:

1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Modeling
5. Evaluation
6. Deployment

Рассматриваются следующие модели:

* Decision Tree;
* Bagging;
* Random Forest;
* Gradient Boosting.

В ходе работы выполняются:

* анализ исходных данных;
* обработка категориальных и числовых признаков;
* построение pipeline предварительной обработки;
* исключение признака `duration` для предотвращения утечки данных;
* обработка значения `pdays=-1`;
* обучение базовых моделей;
* подбор гиперпараметров с помощью `GridSearchCV`;
* подбор гиперпараметров с помощью `RandomizedSearchCV`;
* сравнение моделей;
* оценка качества на тестовой выборке;
* построение матрицы ошибок;
* расчёт основных метрик классификации;
* анализ permutation importance;
* демонстрация влияния утечки данных;
* составление итоговой model card.
