# Лабораторная работа №4 — Теория вероятностей и статистика

Лабораторная работа по дисциплине **«Основы Data Science»**. Выполнены обе части присланного задания: вероятность и статистический вывод. Ноутбуки содержат формулы, рабочий код, численные ответы, графики и интерпретации. При локальном запуске данные берутся из проекта без сетевых запросов; в Colab они скачиваются автоматически.

## Содержание

**Вероятность:** события и условная вероятность; биномиальная модель неявок, 100 000 имитаций и риск перепродажи мест; честная монета и Beta-обновление; вероятности спроса при разных погодных условиях в Bike Sharing.

**Статистика:** описательные статистики и нормальная модель; t-интервал и z-тест; аудит и EDA дневного спроса; влияние способа отбора; t-интервал и bootstrap; проверка заранее выбранного сравнения на 2012 году с Welch t-test; демонстрация ложных находок при 100 проверках.

Во всех выводах отмечены допущения моделей, временная зависимость данных и границы причинной интерпретации.

## Данные и метод

`hour.csv` содержит 17 379 почасовых наблюдений, `day.csv` — 731 дневное наблюдение за 2011–2012 годы. Для вероятностной части порог высокого спроса рассчитывается только на 2011 году, а условные вероятности — на 2012 году. Для статистической части вопрос о рабочих днях сначала формулируется на 2011 году и затем проверяется на 2012 году. Все входные данные и описание кодов признаков находятся локально; происхождение и контрольные суммы файлов приведены в `data/bike-sharing/DATA-CARD.md` и `manifest.json`.

Набор [Bike Sharing Dataset](https://doi.org/10.24432/C5W894): H. Fanaee-T, UCI Machine Learning Repository, 2013; лицензия CC BY 4.0. Данные наблюдательные, поэтому обнаруженная статистическая связь сама по себе не устанавливает причинность.

## Результат

- Для вместимости 100 мест максимальное число бронирований при модельном риске отказа не выше 5% — **151**.
- В 2012 году доля часов высокого спроса составила **0.2406** при неблагоприятной погоде и **0.4852** в остальных погодных условиях.
- Разница среднего дневного спроса между рабочими и нерабочими днями 2012 года — **456.39** поездки; 95%-й Welch-интервал **[29.10; 883.69]**, двустороннее `p = 0.03645`. Это статистическое сравнение наблюдательных дней, а не оценка причинного эффекта.
