# Лабораторная работа 04 — Exploratory Data Analysis

Лабораторная по дисциплине «Основы Data Science». В [ноутбуке](exploratory-data-analysis-lab.ipynb) выполнены семь заданий с таблицами, графиками и Markdown-ответами.

## Содержание

1. Аудит структуры, типов, пропусков и уникальных значений.
2. Среднее, усечённое среднее, медиана и взвешенные оценки.
3. Стандартное отклонение, IQR, масштабированный MAD и boxplot.
4. Гистограммы населения и уровня убийств с KDE.
5. Таблица сопряжённости, условные вероятности и ожидаемое число исходов.
6. Корреляции ETF и диаграмма рассеяния AT&T и Verizon.
7. Hexbin, контуры плотности, сравнение авиакомпаний и фасеты по почтовым индексам.

## Запуск

В PowerShell из корня репозитория выполните следующие команды.

```powershell
cd lab4
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m jupyterlab
```

Откройте `exploratory-data-analysis-lab.ipynb` и выполните все ячейки сверху вниз. Таблицы и графики уже сохранены в ноутбуке.

Архив `data-EDA.zip` должен находиться рядом с ноутбуком. Код читает CSV непосредственно из архива. Для вычислений достаточно локальных данных. Поддержан запуск с рабочим каталогом `lab4` или корнем репозитория.

## Воспроизводимость

Среда проверена на Python 3.13.2. В `requirements.txt` указаны фактически использованные версии. По сравнению с приложенным списком установлены NumPy 2.5.4 и ipykernel 7.4.0. Версии остальных перечисленных библиотек совпадают с приложенным списком.

Для усечённого среднего исключены по 10% наблюдений с каждого края. Взвешенная медиана вычисляется через `wquantiles.median`, MAD — через `statsmodels.robust.scale.mad` с нормировкой около 1,4826. Контуры стоимости жилья используют 10 000 случайных объектов с `random_state=42`, остальные сводки и hexbin — все записи после указанного в ноутбуке фильтра.

Для финансовых рядов сохранена шкала источника. В ноутбуке отмечено расхождение терминов в паспорте данных и лекции. У задержек учитывается доля по причинам перевозчика. Для boxplot и violin plot шкала линейна до 10%, дальше логарифмическая, что позволяет показать весь диапазон до 100%.

Архив содержит исходные CSV, `DATA-CARD.md` с происхождением и SHA-256 файлов, а также `LICENSE-GPL-3.0.txt`.
